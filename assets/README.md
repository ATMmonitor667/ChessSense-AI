# Visual assets for documentation

Use this folder for your **graded submission** screenshots and diagrams.

| File | Purpose |
|------|---------|
| `architecture.mmd` | Mermaid source for the system diagram (copy/paste into [Mermaid Live Editor](https://mermaid.live/), export PNG, save here as `architecture.png`). |
| `architecture.png` | *(Optional but recommended)* Same diagram as raster for embedding in README. |

Keeping a `.mmd` file in-repo documents the diagram in version control without hitting free-tier chart limits elsewhere.
